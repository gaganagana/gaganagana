### Projects

#### 🚌 [Smart Bus – IoT Fare Collection & Tracking](https://github.com/gaganagana/Automatic-Fare-Collection-System-IoT/tree/main/Main-Project/Smart-Bus-IoT-Fare-Collection) *(MCA Major Project)*
- Built as my final year MCA major project to connect physical bus hardware with a mobile application.
- Developed a cross-platform Flutter app where passengers can log in, check their RFID card balance, lock a lost card, top up balance in test mode via Razorpay, and view stops along a simulated 18-stop Bengaluru bus route.
- Connected the Arduino UNO (which controls the RFID reader, servo turnstiles, and DFPlayer bilingual voice alerts in Kannada and English) to a NodeMCU ESP8266 using a simple serial connection with a 1kΩ/2kΩ voltage divider.
- *Technologies:* Flutter, Dart, NodeMCU ESP8266, Arduino UNO, Embedded C, Firebase Auth & Firestore, DFPlayer Mini, MFRC522 RFID.

#### 🎫 [Automatic Fare Collection System with Voice Alert](https://github.com/gaganagana/Automatic-Fare-Collection-System-IoT/tree/main/Minor-Project/Automatic-Fare-Collection-System-with-Voice-Alert) *(MCA Minor Project)*
- My earlier standalone hardware prototype built during my MCA to test cashless bus ticketing.
- Used an Arduino UNO, an MFRC522 RFID reader, an I2C LCD, and two SG90 servo motors for entry and exit gates.
- Calculated fares automatically at ₹10 per stage based on boarding and exit taps, and played voice alerts using a DFPlayer Mini and speaker.
- *Technologies:* Arduino UNO, Embedded C, MFRC522 RFID, DFPlayer Mini, 16x2 I2C LCD, Servo Motors.

#### 🔒 [SecureNote – Encrypted Personal Notes App](https://github.com/gaganagana/secure-note-django)
- A Django web application I built to understand application security and cryptography.
- Private note content is encrypted using Python's `cryptography` (Fernet/AES-128) library before being saved to SQLite, so the database never stores plaintext notes.
- Included user registration/login, strict note ownership checks (users can only access their own notes), and REST API endpoints consumed via JavaScript `fetch()`.
- Wrote 12 unit tests verifying encryption, decryption, authentication, and access controls.
- *Technologies:* Python, Django, Django REST Framework, SQLite, JavaScript, Bootstrap 5, Fernet.

#### 📊 [Supermart Grocery Sales & Retail Analysis](https://github.com/gaganagana/python-fullstack-data-science)
- Exploratory data analysis (EDA) on retail supermarket transactions using Python, Pandas, Matplotlib, and Seaborn.
- Looked at profit margins across categories, customer discount impacts, and regional sales trends.
- Tested basic classification models (Logistic Regression, Decision Tree, Random Forest) on customer datasets to predict customer purchase behavior.
- *Technologies:* Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook.

#### 🛡️ [Cybersecurity Log Monitoring Lab – ELK Stack](https://github.com/gaganagana/cybersecurity-projects)
- A hands-on security lab where I set up and configured the ELK Stack (Elasticsearch, Logstash, Kibana) and Beats to collect and monitor system logs.
- Configured Winlogbeat on Windows to forward security events (like Event ID 4625 for failed logins) and Filebeat on Linux for authentication logs (`/var/log/auth.log`).
- Built Kibana dashboards to filter and visualize login attempts and potential brute-force activity.
- *Technologies:* Elasticsearch, Logstash, Kibana, Winlogbeat, Filebeat, Linux, Windows Event Logs.
